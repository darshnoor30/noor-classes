# NOOR CLASSES

Premium 1-on-1 home tuition and global live online tutoring website.

## Included
- Futuristic WebGL/Three.js hero with orbiting curriculum boards
- Responsive dark + gold premium UI
- Grade 1–12 and board-aware curriculum explorer
- Dynamic 7-step student/parent inquiry form
- Home vs online conditional fields
- Zod + React Hook Form validation
- Tutor recruitment portal
- API route for inquiry validation
- SEO metadata
- Responsive navigation, trust, process, mode, value and CTA sections

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Production notes
The current API validates and acknowledges inquiries but does not persist them. Connect PostgreSQL/Prisma, email/WhatsApp notifications, object storage for tutor documents, and authentication before public production deployment.
